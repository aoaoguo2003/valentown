# ICAC 2026 — Paper 108 presentation

Talk materials for *A Lightweight LLM-Driven Multi-Agent Framework for Virtual Society Simulation with Memory Feedback*
(Aoao Guo, Xinyi Tao, Huakang Li, Xuewu Dai), presented in Parallel Session 3 — Robotics & Autonomous Systems,
Thursday 27 August 2026, 17:35–17:50 BST, room N2.10.

| File | What it is |
|---|---|
| `ICAC2026_Paper108_Valentown.pptx` | The deck — 14 slides, 16:9. The English script is in each slide's speaker notes. |
| `ICAC2026_Paper108_Valentown.pdf` | Same deck as PDF, as a backup for the venue machine. |
| `speech-script.md` | Bilingual (EN script / 中文提示) speaking script: timing table, per-slide text, Q&A preparation. |

The deck runs about 9.5–10.5 minutes at a normal pace. Figures 1–3 are taken from the paper; the
screenshot on slide 8 is `docs/screenshot.png` and the resident sprites come from `frontend/assets/`.

Fonts used: Cambria (headings) and Calibri (body) — both ship with Microsoft Office, so the deck
renders unchanged on a venue machine.
